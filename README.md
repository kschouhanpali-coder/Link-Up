## ✨ Features

- 🔐 **Sign In / Sign Up** - Login and signup pages with show/hide password and a loading state
- 🔄 **Account Switcher** - Switch accounts or sign out from the "Me" menu
- 📰 **Home Feed** - Scrollable feed with posts, images, and videos
- ✍️ **Create Posts** - Write text posts with multiple photos or a video, by upload or web URL
- 👍 **Engagement** - Like, comment, repost (with your own thought), and send posts to a connection
- ✏️ **Edit & Delete Posts** - Manage your own posts with a delete confirmation
- 🤝 **My Network** - Connect and Pending states, network stats, and "People you may know" cards
- 💼 **Jobs** - Recommended jobs with skill tags and salary ranges
- 📨 **Easy Apply** - 3-step application modal: Contact info, Resume, Review
- 🔔 **Notifications** - Unread indicators and live badges in the navbar
- 💬 **Messaging** - Messaging panel with quick send
- 👤 **Editable Profile** - Update name, headline, location, about, profile photo, and banner
- 🏅 **Certifications & Skills** - Add licenses, certifications, and skills with suggestions
- 🍞 **Toast Messages** - Instant feedback such as "Reposted to your network!"

## 🏁 Quick Start

### Use Online
No installation needed! [Launch the live demo](https://linkupclone.netlify.app)

### Run Locally

**Prerequisites:** A modern web browser (Node.js is optional, for a local server)

1. Clone the repository:
```bash
git clone https://github.com/kschouhanpali-coder/linkup-clone.git
cd linkup-clone
```

2. Start the app:
```bash
npx serve .
```
Or simply open `index.html` in your browser.

3. Open `http://localhost:3000` and sign in

## 🎯 How to Use

1. **Sign in** - log in or create a new account
2. **Post** - click **Start a post**, add text, photos, or a video, then publish
3. **Engage** - like, comment, repost, or send posts to your connections
4. **Network** - open **My Network** and connect with people
5. **Apply** - open **Jobs**, choose a role, and click **Easy Apply**
6. **Customize** - edit your profile, photo, banner, certifications, and skills

---

## ⚙️ Easy Apply Steps

| Step | Details |
|------|---------|
| **1. Contact Info** | First name, last name, email, phone, city and state |
| **2. Resume** | Upload a PDF or DOCX, with an optional cover letter |
| **3. Review** | Check the details, confirm, and submit the application |

## 💻 Technologies Used

- **Frontend:** HTML5, CSS3, JavaScript
- **Storage:** Browser localStorage (per browser, no backend)
- **Images:** Unsplash sample content
- **Routing:** Netlify `_redirects` for `/login` and `/signup`
- **Deployment:** Netlify
